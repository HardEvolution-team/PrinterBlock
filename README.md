# PrinterBlock Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **TeeLuk's PrinterBlock** by pitman-87 and TeeLuk.

- Original: http://www.minecraftforum.net/topic/967925-164sspsmplan-teeluks-printerblock-specialarmor/
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.29.0+

This port contains **no original assets**. Put your own copy of the original jar (`tlprinterblock_1.7.10.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
